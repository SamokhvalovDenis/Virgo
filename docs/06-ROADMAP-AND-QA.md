# 06. План реалізації та критерії готовності

> Історичний план попередніх етапів. Поточну реалізацію, готовність та налаштування перевіряйте у [PRE_LAUNCH_REPORT.md](../PRE_LAUNCH_REPORT.md), [DEPLOYMENT.md](../DEPLOYMENT.md) і [contact-form-testing.md](contact-form-testing.md). Згадки про серверну заглушку нижче описують попередній стан; зараз підготовлено вимкнену до налаштування інтеграцію Turnstile + Resend.

## Оцінка

З AI-агентом перший візуальний прототип може з'явитися за 1 день. Готовий комерційний реліз вимагає окремої перевірки даних, права на фото, форми, домену та мобільної версії. **Оцінка — це не гарантія дедлайну.**

## Фактичний стан на 15.10.2026

Позначки нижче означають виконані роботи, а не автоматичну готовність до комерційної публікації.

- Локальна реалізація основних секцій, прайсу, дизайн-системи та базового SEO готова.
- Після появи колекції зображень додано всі 10 знайдених прайсів: 137 рядків / 198 сум у 4 категоріях. Прайс перевірено в установленому Chromium на 360/390/768/1280 px; докладно в `reports/virgo-price-audit.md`. Загальні відкриті пункти production-QA нижче не означають, що цей компонент не перевірявся.
- Візуальну перевірку на 360 / 390 / 768 / 1280px не виконано: інструмент керування браузером не має доступних браузерів. Адаптивні стилі реалізовані, але це не замінює браузерний QA.
- За прямою вимогою користувача реальне надсилання форми не підключається: готові інтерфейс, валідація, API-клієнт і вимкнена серверна заглушка. Спринт 4 нижче є майбутнім етапом після окремого підключення інтеграцій.
- Фото, відгуки, точні контакти, затвердження власниці та юридичні тексти не можна замінити вигаданими даними.
- Контакти, адреса, графік і Facebook уже надані користувачем у `site.ts` та підключені до секції Contact і footer.
- Домен, HTTPS та фінальний деплой не налаштовані. Canonical/sitemap підготовлені до генерації після отримання справжнього URL; аналітика вимкнена.

- [x] Справжні фото відсутні? Показати dev placeholders, не використовувати вигадані салони. Використано декоративну SVG/CSS-графіку; компоненти готові до справжніх фото.

**Критерій:** є естетична порожня “обгортка”, працюють якорі й бронювання.

## Спринт 4. Реальна форма (~2–4 години)

- [ ] Cloudflare Pages Function `/api/contact` — створено вимкнену заглушку 503; реальна обробка відкладена за вимогою користувача.
- [ ] Серверна валідація, Turnstile, антиспам.
- [ ] Resend із підтвердженим доменом відправника.

- [ ] Перевірено весь чеський контент носієм або фахівцем.
- [ ] Власниця затвердила всі ціни, фото, Pluxee, сертифікати, контактні дані.
- [x] Build без помилок, linter без блокуючих проблем.
- [ ] Mobile QA 360 / 390 / 768 / 1280.
- [ ] Усі кнопки запису відкривають Termino. Єдиний URL і безпечні атрибути перевірено тестом; живий перехід/зовнішню сторінку ще треба перевірити.
- [ ] Форма працює на продакшні з Turnstile та Resend.
- [ ] SEO (title, description, h1, sitemap, robots, canonical). Title, description, h1, robots готові; canonical і sitemap очікують production URL.
- [ ] HTTPS, власний домен, metadata OG і favicon. OG і favicon готові; домен та HTTPS ще не налаштовані.
- [ ] Аналітика переходів до запису без PII.
- [ ] Перевірити сторінки Privacy Policy / legal info.
- [ ] Здійснити фінальний деплой.

## Визначення Done

| Питання | Done лише якщо |
|---|---|
| Зручність | користувач із телефона швидко бачить послуги, ціни, запис |
| Відповідність джерелам | немає вигаданих відгуків, контактів, цін |
| Код | UI без бізнес-хардкоду; контент у data-модулях |
| Форма | реально надсилає повідомлення або чесно відключена |
| Кнопки | немає “пустих” кліків |
| SEO | правильна чеська мова й дані локального бізнесу |
| Юридичний мінімум | тексти та політики схвалені власницею |
| Деплой | доступний власний домен, працює HTTPS |

## Ручні сценарії перевірки

1. Обрати `Muži` → ціни змінюються без перезавантаження, є 750–850 Kč для “Celé ruce”.
2. Обрати `Ženy` → 550 Kč для “Celé ruce”.
3. Змінити `women: 400` на `women: 450` у `prices.ts` на тестовій гілці → після збірки видно 450.
4. Перейти на Termino з Hero, прайсу та footer → усі URL валідні.
5. Надіслати форму з некоректним email → помилка клієнта + серверне відхилення.
6. Надіслати коректну форму → власниця отримала лист; `success` лише тоді.
7. Перевірити вкладку без JavaScript? (для Vite SPA вміст обмежений) — SEO слід оцінювати свідомо.
8. Відкрити сайт на 360px → немає горизонтального скролу, прайс читабельний.
9. В `reviews.ts` порожній масив → блок і меню відгуків приховані.
10. Немає адреси → немає фейкової карти, але місто показано.
