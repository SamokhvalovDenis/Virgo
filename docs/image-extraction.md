# Virgo Studio — автоматичний збір фотографій

> Історична інструкція. У поточній робочій копії `scripts/extract-virgo-images.mjs` відсутній; наведена команда зараз не працює. Збережені результати доступні в `reports/virgo-images.json` і `reports/virgo-images.html`. Для оптимізації вже вибраних локальних фото використовуйте `npm run images:optimize`; повторне завантаження джерел для production build не потрібне.

Цей інструмент для твоєї локальної React + Vite розробки збирає зображення, **які браузер реально завантажує** зі сторінки `https://virgostudio.godaddysites.com/`. Скрипт прогортає сторінку, щоб активувати lazy loading, і збирає фото з HTML, CSS-фону та мережевих запитів.

## Підготовка

Скрипт уже розташований у кореневій папці `scripts/`; Playwright є dev-залежністю проєкту. За потреби встановіть залежності через `npm ci` та браузер через `npx playwright install chromium`.

## Запуск із кореня проєкту

```bash
node scripts/extract-virgo-images.mjs
```

## Результати

- `public/images/virgo-original/` — завантажені зображення.
- `reports/virgo-images.html` — наочна галерея для відбору фотографій та прайсів.
- `reports/virgo-images.json` — список URL, імовірні розділи та локальні шляхи.

**Важливо:** скрипт не гарантує, що на сайті відображаються всі можливі прайс-листи. Якщо власниця зберігає прайси поза публічною сторінкою або в закритому GoDaddy-акаунті, їх неможливо зібрати без доступу до цих матеріалів. Не підставляй ціни зі старих рекламних акцій як актуальний прайс. Перед використанням фотографій із сайту уточни у власниці, чи має вона право повторно використовувати їх на новому сайті (частина може бути ліцензованим контентом GoDaddy).

## Як це використати далі

Перевір прайси у галереї. Ціни краще вносити в `src/data/prices.ts` як структуровані дані, а не відображати дрібне зображення прайсу. Після підтвердження власницею заміни тимчасові фотографії в `src/data/services.ts` і `src/data/content.ts` на локальні шляхи `/images/virgo-original/<filename>`.
