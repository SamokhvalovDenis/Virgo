# 02. Дизайн-система — Virgo Beauty Studio

## Концепція: Modern Elegant Wellness

Зберігаємо фірмову атмосферу оригіналу: **бордовий + золото**. Додаємо **теплий кремовий фон**, контрастну типографіку та реальні фото. Не робимо кислотний “beauty UI”, надміру глянцевий luxury або продукт із десятками віджетів.

`references/design-concept.png` — лише композиційний концепт. На ньому є **вигадані фото, відгуки, контактні дані**; переносити їх до публічного сайту заборонено.

## 1. Палітра

| Токен | HEX | Де використовуємо |
|---|---|---|
| `--color-burgundy` | `#421329` | основний темний фон, footer, CTA |
| `--color-burgundy-deep` | `#270C1B` | Hero / hover |
| `--color-cream` | `#FAF5EE` | основний фон |
| `--color-surface` | `#FFFDF9` | картки / форма |
| `--color-gold` | `#D5AE69` | декоративні лінії, акцентні CTA |
| `--color-gold-soft` | `#F1D7A2` | фон світлого CTA на бордовому |
| `--color-ink` | `#271C21` | текст на світлому |
| `--color-muted` | `#6B6063` | другорядний текст |
| `--color-border` | `#E9DCD6` | роздільники |

Не писати білий текст на світло-золотому тлі. Для золотих кнопок використовувати темний текст. Перевіряти контраст WCAG AA.

У Tailwind 4 ці змінні можна визначити в `src/styles/index.css` через `@theme` або звичайний `:root`.

## 2. Шрифти й типографіка

- Заголовки: **Playfair Display** (або Cormorant Garamond), якщо чеська діакритика якісно підтримується.
- Основний текст: **Inter** (або Manrope). Важлива читабельність чеських символів (`ě, š, č, ř, ž, ů`).
- Краще локально хостити webfonts, якщо вирішите юридичні та технічні питання з шрифтами.
- `h1` desktop 48–64px, mobile 34–40px; `h2` desktop 34–44px / mobile 28–32px; body 16–18px; маленький текст не менше 14px.
- Відступ між рядками body 1.5–1.65; текстові колонки шириною до ~65–75 символів.
- **1 заголовок `h1` на сторінку**, логічна ієрархія `h2`/`h3`.

## 3. Сітка та вертикальний ритм

- Контейнер до **1200px**, горизонтальні відступи: mobile 20px, tablet 32px, desktop 40px.
- Проміжок між секціями: desktop 88–112px, mobile 56–72px.
- Картки послуг: 4 колонки >1200px або 3 колонки в стандартному desktop (обирати за реальною шириною), 2 tablet, 1 mobile.
- Картки: radius 16–20px, делікатна тінь, без грубих градієнтів.
- Кнопка: мінімальна висота 44–48px, круглі краї, чітка hover/focus індикація.
- Строгіше ставитися до візуального шуму: не більше 2 акцентних кольорів одночасно.

## 4. Компоненти UI

**Header**
- desktop: логотип зліва, 5–6 навігаційних пунктів по центру, CTA “Rezervovat termín” справа;
- mobile: лого + меню + головна CTA (в меню або внизу);
- sticky при скролі, без перекриття контенту; якірні секції з `scroll-margin-top`;
- меню: Služby, Ceník, O nás, Recenze (лише якщо є), Dárkové poukazy, Kontakt.

**Buttons**
- Primary: золото/світле золото на темному фоні або бордовий на світлому;
- Secondary: outline відповідного контрастного кольору;
- Label чеською, наприклад `Rezervovat termín`, `Zobrazit ceník`, `Kontaktovat studio`.

**ServiceCard**
- реальне фото співвідношення 4:3 / 5:4;
- назва; опис 1–2 рядки; кнопка детальніше; CTA запису;
- без незатверджених цін;
- картинки обрізати природно (`object-fit: cover`) із `alt`.

**PriceList**
- у світлій або темній секції (для настрою можна темно-бордову);
- перемикач `Ženy / Muži` з очевидним активним станом;
- назвa + ціна Kč + CTA; великий список групувати за зонами тіла;
- для `750–850 Kč` показати саме діапазон; не усереднювати.
- на mobile не робити горизонтальний скрол на 320–360px, контент має переноситися;
- на desktop можна показати 2 колонки або групи;
- цін без підтвердження **не вигадувати**.

**Testimonials**
- 3 картки реальних клієнтських відгуків, якщо є;
- автор, текст, джерело (за дозволом), жодних AI-аватарів;
- якщо даних немає — не рендерити секцію та посилання меню.

**ContactForm**
- світла картка, поля `Jméno`, `E-mail`, `Telefon` (необов'язкове, якщо власниця погодить), `Služba` (опційно), `Zpráva`;
- чіткі стани надсилання, помилки біля полів, повідомлення про успіх лише після успішної відповіді API;
- під формою посилання на політику приватності.

## 5. Фотографії — дуже важливо

Перевага: **реальні фотографії салону й процедур**, надані власницею. AI-згенерований настрій придатний для концепту, але не повинен вдавати реальний інтер'єр чи працівників. Не копіювати чужі фото з інтернету без ліцензій.

Рекомендований набір: 1 Hero, 4 категорії, 2–3 інтер'єри, 1 подарунковий сертифікат. Формат WebP/AVIF, підготувати responsive-розміри.

Файли в `public/images/` з простими іменами: `hero.webp`, `massage.webp`, `depilation.webp`, `brows.webp`, `studio-01.webp`, `gift-card.webp`.
**Не вважати, що вони існують** — агент має показувати placeholder до появи реальних зображень.

## 6. Анімації

- легка поява блоків (опційно), hover для карток і CTA;
- 150–250ms, без паралаксу, без autoplay відео;
- `prefers-reduced-motion: reduce` — вимкнення руху.

## 7. Мобільна версія

- 360px — мінімальна практична перевірка;
- одразу помітна CTA бронювання;
- меню доступне з клавіатури та сенсорного екрана;
- картки в одну колонку;
- прайс без дрібного шрифту і без горизонтального прокручування;
- форма, кнопки, відгуки — без накладень;
- зображення не відтягують LCP; `loading="lazy"` для нижніх секцій, Hero — пріоритет.

## 8. Чого НЕ робити

- не ставити вигадані “5.0 / 200+ reviews” та рекламні відзнаки;
- не заповнювати контакти з AI-референса;
- не створювати величезну анімаційну галерею;
- не робити popup запису щоразу при вході;
- не ховати прайс усередині недоступної картинки;
- не генерувати на сторінці фіктивні “акції тільки сьогодні”.
