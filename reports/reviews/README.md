# Секція відгуків Virgo Beauty Studio

Реалізована в існуючому `<Reviews />` між «O nás» та подарунковими сертифікатами. Нові залежності не додавалися. Дані в `src/data/reviews.ts` уже містили всі вісім наданих відгуків і залишені без змін, включно з повними назвами процедур, датами, оригінальними текстами та зауваженням.

## Поведінка

- До 768 px: одна картка; від 768 до 1099 px: дві; від 1100 px: три.
- Стрілки, індикатори сторінок, свайпи та клавіші ArrowLeft / ArrowRight / Home / End у фокусі каруселі. Автоматичного перегортання немає.
- Усі картки мають однакову висоту; текст повний, без line-clamp. На останній desktop-сторінці показуються останні три відгуки, щоб уникнути порожнього місця.
- За межами поточної сторінки картки мають `inert` та `aria-hidden`, тому їхні посилання не перехоплюють клавіатурний фокус. Зміни оголошуються через live region; враховано reduced motion.
- Імен, ініціалів, аватарів та фотографій немає. Оцінка 4,3 / 5 має частково заповнену п'яту зірку; негативне зауваження видиме повністю.
- Кнопка та посилання карток ведуть на наданий Slevomat URL у новій вкладці з `noopener noreferrer`. Підпис пояснює, що це вибірка відгуків. Загальний рейтинг не розраховується.
- Наявна навігація вже автоматично показує відгуки за непорожнього масиву. Зміни App та навігації не знадобилися; порожній масив приховає секцію та пункт меню після перезавантаження застосунку.

## Змінені та додані файли цього завдання

- `src/components/sections/Reviews.tsx`
- `src/components/ui/ReviewCard.tsx`
- `src/components/ui/ReviewsCarousel.tsx`
- `src/components/ui/ReviewsCarousel.css`
- `src/data/content.ts` — лише тексти секції відгуків.
- `src/data/types.ts` — старий контракт Review замінений посиланням на StudioReview.
- `src/data/README.md` — інструкція додавання справжніх відгуків.
- `src/index.css` — видалені лише старі стилі review-card та review-rating.
- `tests/site.test.mjs` — актуалізовані очікування та додані перевірки оригінальних даних.
- `tests/reviews.browser.mjs`
- `reports/reviews/` — цей опис, результати браузерних тестів та скриншоти.

Раніше наявні незакомічені зміни інших секцій збережені.

## Перевірки

```powershell
npm.cmd run lint
npm.cmd run build
npm.cmd test
node tests/reviews.browser.mjs
```

ESLint та TypeScript / production build пройшли. Загальний набір: 29 тестів успішні. Браузерний тест використовує встановлений Playwright Chromium і перевіряє ширини 320, 375, 390, 767, 768, 1024, 1099, 1100 та 1440 px, усі сторінки, точні тексти, геометрію карток, відсутність горизонтального скролу, часткову зірку, зауваження, фокус, кнопки, свайпи, нову вкладку, resize та reduced motion. Для перевірки переходу Slevomat використовується перехоплення запиту без завантаження зовнішнього сайту.

Машинні результати: [browser-results.json](browser-results.json).
