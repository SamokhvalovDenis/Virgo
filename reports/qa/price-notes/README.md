# Перевірка приміток прайсу

Скриншоти `notes-320.png`, `notes-390.png`, `notes-768.png`, `notes-1280.png`, `notes-1920.png` створені тестом `tests/price-notes.browser.mjs` із production-стилями.

Це тестові приклади: довга примітка одного варіанта, спільна примітка картки, картка без приміток і картка з порожніми значеннями. Тексти додаються лише до копії даних у тесті. До `Celková masáž` чи інших процедур у `src/data/prices.ts` нових описів не додано.

Перевірено: перенесення довгого тексту та слів без пробілів, відсутність горизонтального переповнення й перекриття кнопок, однакова висота карток із відсутніми та порожніми примітками, одноразове відображення спільного тексту й відкриття Termino за натисканням `Rezervovat`.

Успішні перевірки: production build, ESLint, 51 тест (`npm test`), 40 комбінацій категорій і ширин у наявному браузерному тесті прайсу та 5 ширин нового браузерного тесту приміток. Після зміни перевірки історичного прайсу повторно пройшли всі 27 тестів сайту та приміток; ESLint також успішний.

Запуск обох браузерних перевірок: `npm run test:prices:browser`.
