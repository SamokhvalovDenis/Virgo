# Редизайн відгуків за наданим референсом

Змінено лише оформлення наявної секції відгуків. Відтворено композицію референсу: золотистий ромб із тонкими лініями, великий бордовий serif-заголовок, сірий підзаголовок, теплі світлі картки з округленням, великі бежево-рожеві лапки, золоті зірочки, тонкий SVG-декор у верхньому правому куті, іконки лотоса й ока та підкреслені посилання на джерело.

Після останнього уточнення користувача типографіку узгоджено з іншими розділами. Заголовок і підзаголовок використовують спільні стилі сайту без окремого збільшення чи жирності. Текст відгуків успадковує основний Inter, 16 px, насиченість 400; колір і міжрядковий інтервал 1,85 збігаються з абзацами сусіднього розділу «O nás». Службові підписи мають типовий розмір 14 px, оцінка — помірну насиченість 500. Мінімальна висота карток — 360 px на desktop і 320 px на mobile. Висота визначається лише картками поточного слайда; довгі тексти показуються повністю.

Логіка `ReviewsCarousel.tsx` не змінювалася: 3 / 2 / 1 картки, стрілки, індикатори, клавіатура, свайпи, відсутність autoplay та доступність збережені. Кнопка переходу до всіх відгуків Slevomat залишена під навігацією. `overflow: clip` запобігає внутрішньому прокручуванню області карток під час переміщення клавіатурного фокуса.

## Змінені файли цього редизайну

- `src/components/sections/Reviews.tsx` — орнамент над заголовком.
- `src/components/ui/ReviewCard.tsx` — декоративні SVG, лапки, іконки категорій та ознака довгого тексту для стилів.
- `src/components/ui/ReviewsCarousel.css` — лише стилі секції відгуків і карток.
- `tests/reviews.browser.mjs` — перевірка видимості рейтингу й дати, тексту без обрізання з урахуванням декоративних лапок, нова папка скриншотів.
- `reports/reviews-reference/` — цей звіт, результати та скриншоти.

Дані `src/data/reviews.ts`, інші секції та навігація не змінювалися. SHA-256 `reviews.ts` до та після редизайну: `3C2DE3271D729D58798633BB2AD7369507C9EB0EDA2B1D914562A1521B040492`.

## Перевірки

- `npm.cmd run lint` — успішно.
- `npm.cmd run build` — TypeScript і production build успішні.
- `npm.cmd test` — 29 / 29 тестів успішні.
- `node tests/reviews.browser.mjs` — Chromium, ширини 320, 375, 390, 767, 768, 1024, 1099, 1100 та 1440 px. Перевірено всі вісім оригінальних текстів, усі сторінки, повну видимість рейтингу й дати, точну оцінку 4,3 та часткову зірку, зауваження, відсутність фото, вирівнювання карток, свайпи, клавіатуру, нову вкладку Slevomat, resize, reduced motion та відсутність горизонтального переповнення.

Браузерний тест також безпосередньо порівнює обчислені шрифт, розмір, насиченість, міжрядковий інтервал, міжлітерний інтервал і колір заголовка та підзаголовка відгуків із розділом послуг, а тексту відгуків — із розділом «O nás» на кожній ширині.

Перший паралельний запуск загального набору мав таймаут очікування контактної форми; послідовний повтор пройшов 29 / 29 без змін у контактній формі.

Повні результати: [browser-results.json](browser-results.json).
